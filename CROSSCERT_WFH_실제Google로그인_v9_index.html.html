계정 및 권한 관리

HR 관리자만 접근할 수 있습니다. Google Workspace 이메일을 기준으로 직원은 본인 정보만, 팀장은 본인과 연결된 팀원만 조회할 수 있습니다.
Google 계정성명권한부서팀상급 팀장관리

Google 로그인 설정

Google Workspace 로그인용 OAuth Web Client가 연결되어 있습니다.
허용 도메인은 현재 crosscert.com으로 설정되어 있습니다.

관리 기준

이상징후 판정 로직
• 고위험: 위험점수 60점 이상 / 중위험: 30~59점 / 저위험: 29점 이하
• 최근 5회 기록에서 동일 이상징후가 2회 이상 반복되면 반복가중치를 추가합니다.
• 동일 근무일에 복수 이상징후가 함께 발생한 기록이 반복되면 추가 가중치를 적용합니다.
• HR은 조치상태를 미조치 → 확인중 → 조치완료로 관리하고 다음 점검일을 기록할 수 있습니다.
업무충실도 판단 원칙
① 업무 시작 시 당일 계획 등록 → ② 근무시간 중 중간 진행내용 확인 → ③ 계획 대비 완료율 → ④ 산출물/처리내역 증빙 → ⑤ 연락·협업 가능 상태 → ⑥ 팀장 확인의 순서로 관리합니다.
단순 접속시간이나 키보드·마우스 움직임이 아니라 실제 업무수행 기록을 중심으로 판단하도록 설계했습니다.

※ 실제 운영 시 사내 SSO, 조직도, 전자결재, 근태시스템 API 연동을 권장합니다.
